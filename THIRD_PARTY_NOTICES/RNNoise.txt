RNNoise optional waveform denoiser

Native RNNoise v0.2 via pyrnnoise==0.4.5 wheel. The project uses the C ABI
directly; it does not vendor or import the PyRNNoise audio-file wrapper.
RNNoise source: https://github.com/xiph/rnnoise/tree/v0.2
PyRNNoise distribution: https://github.com/pengzhendong/pyrnnoise
PyRNNoise wrapper license: Apache-2.0 (included with the installed package).
The RNNoise neural weights are embedded in the native wheel; the run records
the library SHA-256. No native binary or weights are committed here.
